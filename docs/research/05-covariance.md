## 1. Итог в десяти строках

- В MinT нужна ковариация ошибок базовых прогнозов W размера N на N. Для иерархии ЕЭС России N порядка 90. Точное N определит раздел о данных.
- Окно ретроспективной проверки в одну-четыре недели даёт 7–28 суточных начал прогноза. Часовые ошибки внутри суток зависимы, поэтому эффективная длина n_eff мала. Всегда n_eff < p.
- Все классические оценки с сжатием имеют один вид: (1 − λ)·S + λ·T. Они различаются целью T и правилом выбора λ.
- Аналитический вес сжатия убывает примерно как κ/n (Ledoit и Wolf). Байесовская оценка с обратным распределением Уишарта даёт точную форму λ = k/(k + n).
- Вывод для метода A: задавать вес сжатия функцией λ(n) = k/(k + n_eff). Параметр k подбирать по длинной истории, а не по каждому окну.
- Работ с цифрами о пространственной корреляции ошибок суточного прогноза нагрузки между регионами найти не удалось. Это пробел в литературе и одновременно задача для нашего первого опыта.
- Наш разведочный опыт на публичных данных ENTSO-E (через OPSD) показал слабую связь ошибок операторов разных стран: средняя корреляция 0,03. Внутри страны она выше: 0,11 для Германии, 0,14 для Швеции.
- Угроза для статьи: если ошибки предобученных моделей тоже почти не связаны между узлами, структурный априор даст малый выигрыш над диагональным MinT. Нужно измерить это раньше, чем строить метод.
- Предложены три априорные матрицы для ЕЭС: блочная (ОЭС и часовой пояс), ядерная (расстояние), температурная (общая погодная ошибка). Дополнительно описан приём разложения ошибки на согласованную и несогласованную части (раздел 5.4).
- Скачаны 18 статей по теме и пакет данных OPSD (130 МБ). Пути в разделе 9.

## 2. Постановка задачи

### 2.1. Что оценивается

MinT приводит базовые прогнозы ŷ к согласованным ỹ. Формула в проекционном виде:

```
ỹ = ŷ − W·U·(U'·W·U)^(-1)·U'·ŷ,    U'·S = 0
```

Здесь S: матрица суммирования иерархии, W: ковариация ошибок базовых прогнозов (N на N), U: базис пространства несогласованности. Эту форму автор документа вывел сам из задачи наименьших квадратов с весом W^(-1) и ограничением U'·ỹ = 0. Сверьте формулу с Wickramasuriya и др. (2019) до использования в статье.

Практический вывод. Истинный ряд согласован, поэтому U'·ŷ = U'·e, где e: ошибка базового прогноза. Невязку согласования r = U'·ŷ можно вычислить без фактических значений. Согласование равно условному среднему ошибки при известной невязке.

### 2.2. Размерности

| Величина | Значение | Комментарий |
|---|---|---|
| N, число узлов | порядка 90 | 1 ЕЭС, 7 ОЭС, порядка 80 субъектов или энергосистем. Точное число зависит от доступных данных |
| Окно | 1–4 недели | по постановке статьи |
| Начала прогноза | 7–28 суточных | при суточном шаге |
| Часовые ошибки | 168–672 на узел | сильно зависимы внутри суток |
| n_eff | неизвестно, оценить | см. раздел 4.3 |

Вывод: n_eff меньше N во всех режимах постановки. Выборочная ковариация вырождена, её нельзя инвертировать. Сжатие обязательно.

### 2.3. Что важно для MinT

MinT чувствителен не ко всей матрице W, а к направлениям из U. Оценка должна быть положительно определённой. Нужна обратная матрица U'·W·U размера N − m, где m: число узлов нижнего уровня. Для иерархии ЕЭС это примерно 8 на 8, то есть малая матрица.

### 3.3. Формулы весов (проверено по arXiv 0907.4698)

Пусть S: выборочная ковариация, нормированная на n, p: размерность, F = tr(S)/p · I.

```
rho_LW   = sum_i ||x_i x_i' − S||_F^2 / ( n^2 · [tr(S^2) − tr(S)^2 / p] )
rho_RBLW = ( (n−2)/n · tr(S^2) + tr(S)^2 ) / ( (n+2) · [tr(S^2) − tr(S)^2 / p] )
rho_OAS  = ( (1 − 2/p) · tr(S^2) + tr(S)^2 ) / ( (n + 1 − 2/p) · [tr(S^2) − tr(S)^2 / p] )
каждая величина обрезается сверху единицей
```

Общая лемма Ledoit–Wolf в форме Schäfer–Strimmer (из памяти, сверьте со статьёй):

```
lambda* = sum_ij [ Var(s_ij) − Cov(t_ij, s_ij) ] / sum_ij E[ (t_ij − s_ij)^2 ]
```

Для фиксированной цели ковариация равна нулю. Оценка дисперсии: Var(r_ij) = n/(n−1)^3 · sum_k (w_kij − w_ij)^2, где w_kij: произведение стандартизованных значений. Затем λ* ограничивают отрезком от 0 до 1.

### 3.4. Нелинейное сжатие

Ledoit и Wolf (2020) дали аналитическую формулу, которая работает и при p > n. Она не использует структуру, поэтому плохо подходит как единственный метод для нашей задачи. Она подходит как сильный конкурент в сравнении. Пакет `non-linear-shrinkage` (импорт `nonlinshrink`) установлен на маке и проверен на данных 50 на 88: матрица положительно определена.

### 3.5. Байесовская оценка с обратным распределением Уишарта

Пусть W ~ IW(Ψ0, ν0), ошибки в окне имеют нулевое среднее, S: выборочная ковариация, нормированная на n. Апостериорное распределение: IW(Ψ0 + n·S, ν0 + n). Среднее обратного распределения Уишарта равно Ψ/(ν − p − 1). Положим Ψ0 = k·Σ0, где Σ0: априорная матрица, k = ν0 − p − 1. Тогда апостериорное среднее равно:

```
W_post = ( k·Σ0 + n·S ) / ( k + n ) = λ·Σ0 + (1 − λ)·S,    λ = k / (k + n)
```

Это вывод автора документа. Он даёт замкнутую функцию λ(n) с одним параметром k, "размером априорной выборки". Он показывает, что байесовский подход и сжатие в стиле Ledoit–Wolf совпадают по форме. Вес λ убывает как k/n при больших n.

Что делают Carrara и др. (arXiv:2506.19554, проверено по тексту): масштаб Ψ0 = (ν0 − N − 1)·Ψ, где Ψ: ковариация остатков наивного и сезонно-наивного прогнозов с сжатием как в MinT. Степени свободы ν0 выбирают максимизацией leave-one-out логарифмической оценки на отрезке [N + 2, 5N]. Структуры сети в их априоре нет. Это граница новизны для нашего метода A.

### 3.6. Graphical lasso и разреженная обратная матрица

Идея: штрафовать L1-нормой элементы обратной матрицы. Нулевой элемент означает условную независимость узлов при остальных. Для ЕЭС это подходит: соседние ОЭС связаны, далёкие почти нет. Ограничение: при очень малом n результат нестабилен. Параметр α выбирают перекрёстной проверкой. Для структурного априора возможна версия со своим штрафом на каждую пару: меньший штраф для пар из одной ОЭС. Поддержку матричного штрафа в `scikit-learn` автор документа не проверял. В R-пакете glasso она есть (из памяти).

По выдаче поиска, в бенчмарке нагрузки распределительной сети (Nespoli и др., arXiv:1910.03976) MinT с graphical lasso дал лучший результат, а MinT с сжатой ковариацией дал худший. Текст работы не открыт, цифры не проверены. Включите graphical lasso в наши опыты как конкурента.

## 4. Как выбирать вес сжатия

### 4.1. Аналитически

Числитель в лемме Ledoit–Wolf убывает как 1/n. Знаменатель стремится к расстоянию между целью и истинной матрицей. Поэтому λ* ≈ κ/n, где κ не зависит от n. Ledoit и Wolf берут λ̂ = max(0, min(κ̂/n, 1)) (из памяти по статье 2003 года).

Следствия для нас:

- Чем точнее цель, тем меньше знаменатель и тем дольше λ остаётся близким к единице.
- Если цель неверна, λ быстро падает с ростом n, и выборочная ковариация берёт верх.
- В малом опыте на синтетике (раздел 6.1) для верной блочной цели λ ≈ 1 при n до 56. Для неверной цели постоянной корреляции λ падает с 0,93 при n = 7 до 0,22 при n = 365.

### 4.2. Перекрёстная проверка

Допустимые варианты:

- Блочная перекрёстная проверка по времени: обучение на начале окна, оценка на конце. Критерий: гауссовское логарифмическое правдоподобие ошибок на отложенной части. Для вырожденной S это допустимо, потому что оценка с сжатием положительно определена.
- Leave-one-out логарифмическая оценка апостериорной предсказательной плотности, как у Carrara и др.
- Повторная выборка для выбора параметра (Bickel, Levina 2008) для полос и порогов.
- Для graphical lasso: `GraphicalLassoCV` из `scikit-learn` (в установленной версии есть).
- Прямая оптимизация итоговой метрики (энергетическая оценка после согласования). При окне в одну-четыре недели шум этой метрики велик.

Предложение для метода A. Не подбирайте λ для каждого окна. Подберите один раз функцию λ(n) = k/(k + n_eff) по длинной истории. Для этого выберите k, который минимизирует энергетическую оценку согласованных прогнозов на множестве окон разной длины. Тогда работа на короткой истории не требует перекрёстной проверки.

### 4.3. Эффективная длина выборки

Ошибки зависимы во времени. Оценка Var(r_ij) в лемме должна учитывать автокорреляцию. Иначе λ получается ниже нужного, и сжатие слабее нужного. Два способа:

- Оценка Newey–West для среднего произведения w_kij (Newey, West 1987, Econometrica 55(3), 703–708, проверено по каталогу).
- Блочный бутстреп по суткам.

Грубая оценка: n_eff = n / (1 + 2·Σ_k ρ_k), где ρ_k: автокорреляции произведений стандартизованных ошибок. Значение для наших данных пока не измерено. Это первый опыт, который нужно провести (раздел 7).

### 4.4. Как вес зависит от n: сводка

| Режим | Поведение λ | Основание |
|---|---|---|
| n ≪ p | λ близок к 1 для разумной цели | синтетика, раздел 6.1 |
| n ≈ p | λ около 0,3–0,6 для неточной цели | синтетика |
| n ≫ p | λ → 0 как κ/n | теория Ledoit–Wolf |
| Любое n, цель верна | λ остаётся высоким дольше | синтетика |
| Любое n, зависимые ошибки | λ ниже нужного без поправки на n_eff | раздел 4.3 |

## 5. Что известно о пространственной связи ошибок прогноза нагрузки

### 5.1. Прямые числа: чего нет

Запрос был такой: корреляция ошибок суточного прогноза нагрузки между регионами, работы с цифрами. Около десяти запросов на английском и русском дали такие результаты:

- Работы с таблицей корреляций ошибок прогноза нагрузки между зонами оператора системы найти не удалось.
- Отчёты Системного оператора с оценкой точности по ОЭС в выдаче не найдены. Методика СО ЕЭС описывает оценку точности и балансировку прогнозов на уровнях ОДУ и ЦДУ, но цифр в доступных страницах нет.
- Ближайшие по смыслу работы относятся к ветру, температуре и временной иерархии нагрузки. Они перечислены ниже.

Это пробел, а не доказательство отсутствия. Перед отправкой статьи повторите поиск на сайтах операторов (PJM, ERCOT, MISO, RTE, Elia, ENTSO-E).

### 5.3. Роль температуры

Идея для априорной матрицы. Пусть e_i: ошибка нагрузки узла i, τ_i: ошибка прогноза температуры в узле i, β_i: чувствительность нагрузки к температуре. Тогда e_i = β_i·τ_i + ε_i, и cov(e_i, e_j) = β_i·β_j·cov(τ_i, τ_j) при независимых ε. Ковариация погодных ошибок известна лучше, чем ковариация ошибок нагрузки: для неё есть многолетние ряды. Гипотеза для проверки: доля общей погодной составляющей в ошибке нагрузки достаточно велика.

Предостережения:

- Jang и Matteson показывают, что на коротком горизонте пространственная связь ошибок температуры слабее. Для суточного прогноза выигрыш может быть малым.
- Предобученная модель получает историю нагрузки, а температуру только если её подали как ковариату. Без ковариаты ошибка модели содержит погодную составляющую целиком. С ковариатой часть уходит в ошибку погодного прогноза.
- Общие синоптические события (холодная волна, жара, фронт) дают редкие, но сильные совместные ошибки. Ковариация в таких режимах выше средней. Нужна ковариация по режимам, а не одна на все дни. Это гипотеза.
- Чувствительность β_i нелинейна: выше при морозе и жаре, ниже в нейтральную погоду.

Источники температуры, проверенные в этой сессии:

### 5.4. Разложение ошибки на согласованную и несогласованную части

Модель: e = S·e_b + δ, где e_b: ошибка нижнего уровня, δ: ошибка, специфичная для агрегатов (нулевая на нижнем уровне). Тогда U'·e = δ_агр, то есть δ наблюдаема по прогнозам без фактических значений (раздел 2.1). Если e_b и δ независимы, то:

```
W0 = S·Σ_b·S' + blockdiag(Σ_δ, 0) + малая диагональ для положительной определённости
```

Следствия:

- Σ_δ имеет размер порядка 8 на 8 (ЕЭС и ОЭС). Её можно оценить по длинной истории прогнозов, без фактических значений, с обычным сжатием.
- Σ_b имеет размер m на m, m порядка 80. Её оценивают по короткому окну и по структурному априору из разделов 5.5–5.7.
- Неверное допущение независимости даст смещение. Проверьте его регрессией e_b на r.

Приём автор документа вывел сам. Новизну относительно литературы не проверяли. Используйте его как вспомогательный, если априор для всей матрицы окажется слишком грубым.

### 5.5. Вариант П1: блочный априор по ОЭС и часовому поясу

Определение для стандартизованных ошибок (деление на масштаб узла):

```
R0_ij = rho_in_OES    если узлы i и j в одной ОЭС
      = rho_tz        если ОЭС разные, а часовой пояс одинаков
      = rho_out       иначе
Sigma0 = D^(1/2) · R0 · D^(1/2),    D: диагональ дисперсий (сжатая отдельно)
```

Параметры: три общих значения или три плюс по одному ρ_in на каждую ОЭС (всего 9). Оценка: среднее выборочных корреляций по всем парам каждого типа в окне. Пар порядка тысяч, поэтому среднее устойчиво даже при малом n. Но пары зависимы через общий фактор, поэтому доверительные границы стройте блочным бутстрепом.

Что проверять:

- Положительную определённость R0 (собственные значения, при необходимости срез).
- Контрольный опыт: случайно перемешайте метки ОЭС. Если качество не падает, структура не нужна.
- Отличие ρ_in от ρ_out за пределами шума.

Часовой пояс в этом варианте задаёт сдвиг суточной формы нагрузки. Узлы разных поясов имеют разное время пика. Ошибка фазы даёт отрицательную или малую связь. Это гипотеза.

### 5.6. Вариант П2: ядро по расстоянию

```
R0 = (1 − a)·I + a·K,    K_ij = exp(−d_ij / ell)
Sigma0 = D^(1/2) · R0 · D^(1/2)
```

d_ij: расстояние по дуге большого круга между центрами нагрузки узлов. Центры лучше брать по взвешенным населённым пунктам, а не по границам субъекта. Параметры a и ℓ оценивают по сетке на парах в окне. Экспоненциальное ядро от расстояния по сфере допустимо (Gneiting 2013, по аннотации): оно положительно определено. Матрица R0 положительно определена при a < 1.

Расширение: добавить индикатор одной ОЭС и получить смесь П1 и П2 с весами по пулу пар (многоцелевое сжатие в духе Lancewicki и Aladjem).

Что проверять:

- Убывает ли оценка корреляции с расстоянием (график по корзинам расстояния).
- Хватает ли одного ℓ для всей страны. Территория ЕЭС неоднородна: плотность узлов на европейской части выше, чем на востоке. Возможно, нужен радиус, зависящий от региона.

### 5.7. Вариант П3: температурный априор

```
Sigma0 = B · C_T · B + D_eps
B = diag(beta_i),    C_T: ковариация ошибок прогноза температуры между узлами
D_eps: диагональ остаточных дисперсий
```

β_i оценивают по длинной истории нагрузки и температуры (кусочно-линейная зависимость от температуры, по часам суток и дням недели). C_T оценивают двумя способами:

- по архиву прогнозов погоды и данным реанализа (ошибка прогноза температуры), история короче;
- по аномалиям температуры реанализа ERA5 (отклонение от климатической нормы), история длинная, но связь завышена.

Что проверять:

- Корреляцию между элементами C_T и выборочной корреляцией ошибок нагрузки в длинной выборке.
- Различие двух вариантов C_T: прогнозные ошибки против аномалий.
- Режимное разбиение: отдельно дни с аномалией выше порога.

### 5.8. Сравнение вариантов

| Вариант | Число параметров | Данные кроме ошибок | Сильная сторона | Слабая сторона |
|---|---|---|---|---|
| П1 | 3–9 | карта ОЭС, часовые пояса | просто, устойчиво | груб внутри ОЭС |
| П2 | 2 (a, ℓ) | координаты центров нагрузки | гладкая связь с расстоянием | нужны разумные центры |
| П3 | 1 на узел плюс C_T | температура, длинная история нагрузки | физический смысл, длинная история | зависит от того, подана ли температура модели |

## 8. Связь с угрозами новизне

Файл 04-novelty.md уже перечисляет близкие работы. Из этого раздела следуют уточнения.

- Идея "сжатие ковариации к априору" занята: Carrara и др. (2025) по Уишарту, Møller и др. (2024), Li и др. (2026). Новыми могут быть источник априора (ОЭС, часовой пояс, температура, расстояние) и функция веса от n.
- У Carrara и др. ν0 выбирается по leave-one-out для каждого набора данных, закона от длины окна нет. Наша функция k/(k + n_eff) с параметром, обученным по длинной истории, отличается. Статью Li и др. (arXiv:2608.13886) прочтите целиком: аннотация упоминает сжатие, цель не названа.
- Вопрос рецензента: если есть длинная история прогнозов, зачем короткое окно. Ответы: нестационарность ковариации (сезон, режим), стоимость обратного прогона больших моделей, новые узлы. Это нужно прописать во введении и проверить опытом D5 на окнах разного возраста.
- Hansen и др. (2023) показали, что структура ковариации во времени устойчива. Это довод против быстрой адаптации и в пользу длинной истории для априора.
